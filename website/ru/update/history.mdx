<Update label="2026-9-17" tags={["Новые функции","Оптимизация","Исправления"]} description="v0.6.3">
  ## Изменения

  - Новое: автоматизация Wi-Fi может переключать профиль при подключении к указанной сети, другой Wi-Fi или при отсутствии Wi-Fi
  - Новое: импорт пользовательского ядра по HTTPS-ссылке или ZIP-плагину с немедленным включением
  - Новое: загрузка GeoX `Model.bin` (модель LightGBM) для ядра Smart
  - Новое: стек MIPS для VpnService, переключение между gVisor и MIPS
  - Новое: внешний контроллер поддерживает HTTP/HTTPS, проверку доступности и откат к локальной среде выполнения
  - Новое: внешние панели с выбором протокола и кнопкой открытия; URL содержит данные активного контроллера
  - Новое: поддержка разрешения локальной сети Android 17 (`ACCESS_LOCAL_NETWORK`) при открытии нелокальной панели
  - Новое: в режиме eBPF добавлена опция обхода IP материкового Китая в ядре
  - Новое: на главной Moe добавлен переключатель затемнения нижней части обоев
  - Новое: на планшете в двухпанельном виде можно запускать тест задержки со страницы сведений о прокси
  - Улучшено: выбор ядра переведён на нижнюю шторку; режим eBPF показывается только при доступности
  - Улучшено: раскладка окна определяется по короткой стороне, чтобы смартфон в портрете не получал планшетный интерфейс
  - Улучшено: скругления, отступы нижней панели, градиент обоев и длинные переходы основной навигации
  - Обновлено: User-Agent подписки по умолчанию — `ClashMetaForAndroid/2.11.33`
  - Обновлено: превью на главной документации заменено на зацикленное автовоспроизведение видео
  - Исправлено: скомпилированный YAML VpnService содержал `tun.stack`, из-за чего ядро отклоняло конфигурацию
  - Исправлено: panic компилятора JS-переопределений проходил через JNI и завершал процесс Android
  - Исправлено: прокрутка списка контроля доступа и сортировка выбранных приложений после повторного входа
  - Обновлено: зависимости mihomo / gVisor / mipstack / Tailscale и `boa_engine` компилятора переопределений

  **Full Changelog**: [https://github.com/YumeYucca/YumeBox/compare/v0.6.2...v0.6.3](https://github.com/YumeYucca/YumeBox/compare/v0.6.2...v0.6.3)

<Update label="2026-7-27" tags={["功能更新","优化","修复"]} description="v0.6.0">
  ## 更改

  - **重构并极限精简应用壳层**，压缩应用 Dex 与原生载荷，显著降低 APK 打包体积
  - **新增独立 Package 打包模块与自定义 APK Packer**，统一处理载荷压缩、ABI 打包、完整性校验、动态加载、对齐和签名
  - **完全重写底层 Core API 通信架构**，移除旧 JNI 业务桥接，统一通过 mihomo REST API 连接本地与远程控制器
  - **移除纯代理模式，路由改动 VPN Service 、Tun 与透明代理；透明代理目前仅提供有限支持，功能尚不完整**
  - 重构运行时 API、客户端与服务分层，内核改为独立进程运行，并加强会话、进程和状态管理
  - 清理旧 Go/C Bridge、JNI Helper 和废弃原生 API，重构 Go 内核入口与 Rust 覆写编译器结构
  - 新增平板与大屏主从双栏布局，代理节点支持自适应网格展示和右侧详情切换
  - 新增定位当前代理节点功能，并优化列表、网格的定位滚动和代理页稳定性
  - 新增连接详情页面，补充连接信息标签与页面导航
  - 新增运行时规则搜索、筛选和临时启用/禁用功能
  - 新增按小时记录流量统计，改善统计数据写入与展示
  - 新增覆写**应用到配置**界面，可查看和修改覆写与多个订阅配置之间的绑定关系
  - 自定义分流配置支持跳过默认运行时 Patch，避免高级配置被应用自动修改
  - 新增外部 HTTP Provider 预取，订阅启动前会将 Provider 下载到对应配置目录
  - 订阅下载支持解析请求头、跟随重定向和自定义 User-Agent，并显示下载进度
  - 新增繁体中文和日语界面翻译，内置配置名称支持本地化
  - 修复首页设置、编辑器、自定义分流、远程控制器及无障碍操作的多语言缺失
  - 新增内核诊断导出；运行时、内核和配置测试日志统一为带时间戳的 `runtime.log`
  - 日志不再在每次启动时清空，保留完整错误原因并限制文件最大体积
  - 构建信息新增 mihomo 分支哈希与内核版本标记，便于识别和排查内核版本
  - 配置重载和远程控制器模式下继续显示代理入口与当前代理目标，减少页面状态跳变
  - 优化配置列表分区、底部操作面板和内置/导入配置的展示逻辑
  - 开源许可页面改为直接打开项目链接，精简中间弹窗
  - 优化启动流程，将重任务移至后台线程，并加强自动启动、会话追踪和运行状态恢复
  - 优化本地与 Root 运行时生命周期，防止过期会话、重复失败提示及连续启动竞争
  - 优化代理组启动校验：增加超时、中断响应、内核存活检查和错误日志回溯
  - 优化覆写执行，复用 JavaScript 运行时、跳过空覆写链，并避免应用操作等待运行时重载
  - 优化内置覆写的物化、元数据修复和配置处理，内置 DNS 防泄漏覆写改为 YAML 资源
  - Оптимизируйте системную панель и поля метода ввода редактора, чтобы улучшить возможности полноэкранного редактирования.
  - Оптимизируйте боковую панель и анимацию страниц с двумя столбцами, закругленные углы и эффекты размытия, а также используйте рендеринг Haze для боковой панели.
  - Устранена проблема, из-за которой узел поставщика отображается как неизвестный тип, задержка не может быть отображена, а время проверки скорости одного узла всегда истекает.
  - Исправлена ​​проблема, из-за которой конфигурация DNS по умолчанию добавляла недопустимый сервер `system://`, в результате чего каждое разрешение создавало неудачную ветвь.
  - Исправлена ​​проблема, из-за которой старый экземпляр завершался не полностью, а путь к сокету был неправильно заменен, когда демон Root запускался постоянно.
  - Исправлена ​​проблема, из-за которой собственный подпроцесс ядра не перезапускался после выхода и становился процессом-зомби.
  - Исправлена ​​проблема отсутствия повторной попытки после прерывания отправки сообщения владельца сокета, а также проблема ненормальной обработки подключенных сокетов Unix.
  - Исправлена ​​проблема, из-за которой ключи контроллера были доступны через командную строку процесса.
  - Исправлена ​​проблема, из-за которой плитка быстрых настроек не может остановить службу, статус не синхронизирован и не может быть восстановлен после исключения.
  - Исправлена ​​проблема, из-за которой автоматический запуск без интерфейса не позволял возобновить работу, а также проблема с сохранением локального состояния в остановленном процессе.
  - Исправлены такие проблемы, как пустой импорт подписок, ненормальный контент, недопустимые типы или размеры ресурсов изображений и т. д.
  - Исправлен сбой при запуске дополнительного магазина, вызванный обрезкой класса Javet после сжатия R8.
  - Исправлена ​​проблема, из-за которой строка заголовка всплывающего окна агента не сохранялась в состоянии подписки, а состояние кнопки истекало после восстановления фона.
  - Исправлена ​​проблема, из-за которой жест двойного щелчка на домашней странице не работал, а боковую панель нельзя было убрать после ее раскрытия.
  - Исправлена ​​проблема, из-за которой опрос домашней страницы и прокси-страницы не прекращался при очистке ViewModel.
  - В процессе выпуска добавлены варианты Arm64-v8a и Universal, Geo и NoGeo, а также унифицировано именование APK-файлов.
  - Локальная сборка по умолчанию генерирует только Arm64-v8a. Вы можете включить все ABI или переключить упаковку географических ресурсов с помощью переключателя сборки.
  - CI поддерживает одновременное создание версий Geo/NoGeo, публикацию универсальных APK и создание однозначных названий продуктов по вариантам.

  - Обновите конфигурацию сборки Android до AGP 9 и вместо этого используйте схему нумерации версий на основе количества коммитов.
