<Update label="2026-9-19" tags={["機能更新","最適化","修正"]} description="v0.6.4">
  ## 変更

  - プロキシの遅延テストとヘルスチェックを再構成。グループ単位の overlay、進捗表示、結果のまとめて更新に対応
  - プロキシツールバーにノード検索・並べ替え・遅延テストを統合し、テスト中のリスト更新を改善
  - プレビュー実行時とプロキシ未起動時のヘルスチェックを強化し、遅延結果を統一
  - 外部コントローラーの到達確認とノードリストの非ブロッキング更新を統合し、リモートモードの引っかかりを軽減
  - Moe ホームの壁紙下部暗転スイッチを削除。角丸から壁紙が見えないよう常に下部を暗転
  - 国・地域フラグ表示ロジックを最適化
  - Android NDK と Go モジュール依存を更新

  **Full Changelog**: [https://github.com/YumeYucca/YumeBox/compare/v0.6.3...v0.6.4](https://github.com/YumeYucca/YumeBox/compare/v0.6.3...v0.6.4)
</Update>

<Update label="2026-9-17" tags={["機能更新","最適化","修正"]} description="v0.6.3">
  ## 変更

  - 新規: Wi-Fi 自動化で指定プロファイルへの切り替えに対応。対象 Wi-Fi、その他の Wi-Fi、未接続時に VPN を起動して設定を切り替え可能
  - 新規: カスタムカーネルの取り込み。HTTPS リンクまたはプラグイン ZIP からインストールしてすぐ有効化
  - 新規: Smart カーネル向け GeoX `Model.bin`（LightGBM モデル）のダウンロード
  - 新規: VpnService に MIPS プロトコルスタックを追加し、gVisor / MIPS を切り替え可能
  - 新規: 外部コントローラーで HTTP / HTTPS を選択可能。到達確認に失敗が続くとローカル実行へフォールバック
  - 新規: 外部パネルのプロトコル選択と起動入口。現在のコントローラー接続情報を URL に付与
  - 新規: Android 17 のローカルネットワーク権限に対応。ローカル以外のパネルを開くときに `ACCESS_LOCAL_NETWORK` を要求
  - 新規: eBPF モードに「中国大陸 IP をカーネルでバイパス」オプションを追加
  - 新規: Moe ホームに壁紙下部の暗転スイッチを追加
  - 新規: タブレットの分割表示でプロキシ詳細から直接遅延テスト可能
  - 最適化: カーネル選択をボトムシートに変更。eBPF 実行モードは利用可能な場合のみ表示
  - 最適化: 最短辺でタブレット / スマホを判定し、スマホ縦向きで分割レイアウトに入らないように調整
  - 最適化: 角丸、ボトムバー余白、壁紙グラデーション、メインナビの長距離ジャンプ
  - 更新: サブスクのデフォルト User-Agent を `ClashMetaForAndroid/2.11.33` に変更
  - 更新: ドキュメントトップのプレビューを自動再生ループ動画に変更
  - 修正: VpnService のコンパイル設定に `tun.stack` が書き込まれ、カーネルが拒否する問題
  - 修正: JS オーバーライドコンパイラの panic が JNI を越えてアプリをクラッシュさせる問題
  - 修正: アクセス制御リスト再入時のスクロール位置と選択優先ソートのずれ
  - 更新: mihomo / gVisor / mipstack / Tailscale とオーバーライドコンパイラの `boa_engine` を追従

  **Full Changelog**: [https://github.com/YumeYucca/YumeBox/compare/v0.6.2...v0.6.3](https://github.com/YumeYucca/YumeBox/compare/v0.6.2...v0.6.3)
</Update>

<Update label="2026-7-27" tags={["功能更新","优化","修复"]} description="v0.6.0">
  ## 更改

  - **重构并极限精简应用壳层**，压缩应用 Dex 与原生载荷，显著降低 APK 打包体积
  - **新增独立 Package 打包模块与自定义 APK Packer**，统一处理载荷压缩、ABI 打包、完整性校验、动态加载、对齐和签名
  - **完全重写底层 Core API 通信架构**，移除旧 JNI 业务桥接，统一通过 mihomo REST API 连接本地与远程控制器
  - **移除纯代理模式，路由改动 VPN Service 、Tun 与透明代理；透明代理目前仅提供有限支持，功能尚不完整**
  - 重构运行时 API、客户端与服务分层，内核改为独立进程运行，并加强会话、进程和状态管理
  - 清理旧 Go/C Bridge、JNI Helper 和废弃原生 API，重构 Go 内核入口与 Rust 覆写编译器结构
  - 新增平板与大屏主从双栏布局，代理节点支持自适应网格展示和右侧详情切换
  - 新增定位当前代理节点功能，并优化列表、网格的定位滚动和代理页稳定性
  - 新增连接详情页面，补充连接信息标签与页面导航
  - 新增运行时规则搜索、筛选和临时启用/禁用功能
  - 新增按小时记录流量统计，改善统计数据写入与展示
  - 新增覆写**应用到配置**界面，可查看和修改覆写与多个订阅配置之间的绑定关系
  - 自定义分流配置支持跳过默认运行时 Patch，避免高级配置被应用自动修改
  - 新增外部 HTTP Provider 预取，订阅启动前会将 Provider 下载到对应配置目录
  - 订阅下载支持解析请求头、跟随重定向和自定义 User-Agent，并显示下载进度
  - 新增繁体中文和日语界面翻译，内置配置名称支持本地化
  - 修复首页设置、编辑器、自定义分流、远程控制器及无障碍操作的多语言缺失
  - 新增内核诊断导出；运行时、内核和配置测试日志统一为带时间戳的 `runtime.log`
  - 日志不再在每次启动时清空，保留完整错误原因并限制文件最大体积
  - 构建信息新增 mihomo 分支哈希与内核版本标记，便于识别和排查内核版本
  - 配置重载和远程控制器模式下继续显示代理入口与当前代理目标，减少页面状态跳变
  - 优化配置列表分区、底部操作面板和内置/导入配置的展示逻辑
  - 开源许可页面改为直接打开项目链接，精简中间弹窗
  - 优化启动流程，将重任务移至后台线程，并加强自动启动、会话追踪和运行状态恢复
  - 优化本地与 Root 运行时生命周期，防止过期会话、重复失败提示及连续启动竞争
  - 优化代理组启动校验：增加超时、中断响应、内核存活检查和错误日志回溯
  - 优化覆写执行，复用 JavaScript 运行时、跳过空覆写链，并避免应用操作等待运行时重载
  - 优化内置覆写的物化、元数据修复和配置处理，内置 DNS 防泄漏覆写改为 YAML 资源
  - エディターのシステム バーと入力メソッドのマージンを最適化して、全画面編集エクスペリエンスを向上させます.
  - サイドバーと 2 列ページのアニメーション、丸い角、ぼかし効果を最適化し、サイドバーに Haze レンダリングを使用します.
  - プロバイダノードが不明なタイプとして表示され、遅延が表示されず、単一ノードの速度テストが常にタイムアウトになる問題を修正します.
  - デフォルトの DNS 構成によって無効な `system://` サーバーが追加され、各解決で失敗したブランチが生成される問題を修正しました.
  - Root デーモンが継続的に起動されたときに、古いインスタンスが不完全に終了し、ソケット パスが誤って置き換えられる問題を修正しました.
  - ネイティブ カーネル サブプロセスが終了後にリサイクルされず、ゾンビ プロセスになる問題を修正しました.
  - ソケットオーナーのメッセージ送信が中断されてリトライしない問題と、接続したUnixソケットの処理が異常になる問題を修正
  - コントローラー キーがプロセス コマンド ライン経由で公開される問題を修正しました
  - クイック設定タイルでサービスを停止できず、ステータスが同期せず、例外発生後に復元できない問題を修正しました.
  - インターフェイスレス自動起動で動作を再開できない問題と、停止したプロセスにローカル状態が残る問題を修正しました.
  - サブスクリプションの空のインポート、異常なコンテンツ、不正な画像リソースのタイプやサイズなどの問題を修正しました.
  - R8 圧縮後に切り取られる Javat クラスによって引き起こされるサブストア起動時のクラッシュを修正
  - サブスクリプション状態でエージェントポップアップウィンドウのタイトルバーの操作が持続せず、背景が復元された後にボタン状態が期限切れになる問題を修正しました.
  - ホームページでのダブルクリックジェスチャーが失敗し、サイドバーを展開した後に元に戻せない問題を修正しました.
  - ViewModel のクリーンアップでホーム ページとプロキシ ページのポーリングが停止しない問題を修正しました
  - リリース プロセスでは、arm64-v8a とユニバーサル、Geo および NoGeo のバリアントが追加され、APK ファイルの名前が統一されます.
  - ローカル ビルドはデフォルトで arm64-v8a のみを生成します.すべての ABI を有効にすることも、ビルド スイッチを使用して Geo リソース パッケージを切り替えることもできます.
  - CI は、Geo/NoGeo バージョンの同時構築、ユニバーサル APK の公開、バリアントごとの明確な製品名の生成をサポートします.
  - APK を公開して、統合された 16 KiB ページの配置、整合性チェック、パッケージ化後の再署名を実行します.
  - Android ビルド構成を AGP 9 に更新し、代わりにコミット数ベースのバージョン番号付けスキームを使用します.
