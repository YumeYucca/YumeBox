## Introduction

[YumeBox](https://github.com/YumeYucca/YumeBox) is a branch management tool based on the visual novel [9-nine- ARTEISIA](https://9-nine-project.com/game/asnine), which adds some easy-to-use functions


Before using YumeBox, please know:
    - This project is an expansion of 9-nine- ARTEISIA. To play the visual novel, please go to [9-nine-project](https://9-nine-project.com/game/asnine)
    - The copyright of the [YumeBox](https://github.com/YumeYucca/YumeBox) application icon and brand logo belongs to the project owner
    - Branch versions must not use [YumeBox](https://github.com/YumeYucca/YumeBox) `项目名称` and continue to use `原始图标`
    - First-party content for forked releases must not contain content related to the [Memory Overflow Working Group](https://oom-wg.dev/), including domain names
      (such as `*.oom-wg.dev`, `*.gal.tf`, etc.), channels or group chats, etc.

These should not be used in any forked version except for justification [YumeBox](https://github.com/YumeYucca/YumeBox) Original project source

## Special

**~~The author knows nothing about the code in this project. The code is either available or unavailable, there is no third case. ~~**

**The core concept of YumeBox is to overwrite as little content as possible in the original configuration, do not overwrite unless necessary, and refuse to abstract clear configuration [fields] (https://wiki.metacubex.one/config/) into ambiguous and ambiguous function switches**
## Development

The iterations of YumeBox have gradually stabilized so far, and will remain **Open Source & Free** in the future, promising that there will be no privacy collection, uploading or advertising.

### **June 1, 2026**

***In order to maintain the good development of the project, the signature verification part has been removed. In addition, some terms have been added to limit the release of branch versions only. Please do not bring confusion, ambiguity or unnecessary burden to this project***
