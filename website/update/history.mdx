<Update label="2026-9-17" tags={["功能更新","优化","修复"]} description="v0.6.3">
  ## 更改

  - 新增 Wi-Fi 自动化切换配置：连接指定 Wi-Fi、其他 Wi-Fi 或未连接 Wi-Fi 时，可启动 VPN 并切换到指定配置
  - 新增自定义内核导入：支持填写内核链接或上传插件 ZIP，安装后直接启用
  - 新增 GeoX `Model.bin`（LightGBM 模型）下载，供 Smart 内核使用
  - VpnService 新增 MIPS 协议栈，可在 gVisor / MIPS 之间切换
  - 外部控制器支持选择 HTTP / HTTPS，并增加连通性探测；连续失败后回退本地运行时
  - 外部面板支持选择面板协议，并新增打开入口；面板 URL 会带上当前控制器的连接信息
  - 适配 Android 17 局域网权限，打开非本机外部面板时会请求 `ACCESS_LOCAL_NETWORK`
  - eBPF 模式新增「国内 IP 不过核心」
  - Moe 首页新增「壁纸底部渐暗」开关
  - 平板双栏代理详情页支持直接测速
  - 优化内核选择交互，改为底部弹窗；eBPF 运行模式仅在设备可用时显示
  - 优化窗口布局判断：按最短边区分平板 / 手机，避免手机竖屏进入双栏
  - 优化圆角、底栏内边距、首页壁纸渐变，以及主导航长距离跳转
  - 订阅默认 User-Agent 改为 `ClashMetaForAndroid/2.11.33`
  - 文档首页预览改为自动播放循环视频
  - 修复 VpnService 编译配置写入 `tun.stack` 导致内核解析失败
  - 修复 JS 覆写编译器 panic 穿过 JNI 导致应用崩溃
  - 修复访问控制列表重新进入后滚动位置和已选优先排序不同步
  - 跟进 mihomo / gVisor / mipstack / Tailscale 等依赖，以及覆写编译器使用的 `boa_engine`

  **Full Changelog**: [https://github.com/YumeYucca/YumeBox/compare/v0.6.2...v0.6.3](https://github.com/YumeYucca/YumeBox/compare/v0.6.2...v0.6.3)
</Update>

<Update label="2026-7-27" tags={["功能更新","优化","修复"]} description="v0.6.0">
  ## 更改

  - **重构并极限精简应用壳层**，压缩应用 Dex 与原生载荷，显著降低 APK 打包体积
  - **新增独立 Package 打包模块与自定义 APK Packer**，统一处理载荷压缩、ABI 打包、完整性校验、动态加载、对齐和签名
  - **完全重写底层 Core API 通信架构**，移除旧 JNI 业务桥接，统一通过 mihomo REST API 连接本地与远程控制器
  - **移除纯代理模式，路由改动 VPN Service 、Tun 与透明代理；透明代理目前仅提供有限支持，功能尚不完整**
  - 重构运行时 API、客户端与服务分层，内核改为独立进程运行，并加强会话、进程和状态管理
  - 清理旧 Go/C Bridge、JNI Helper 和废弃原生 API，重构 Go 内核入口与 Rust 覆写编译器结构
  - 新增平板与大屏主从双栏布局，代理节点支持自适应网格展示和右侧详情切换
  - 新增定位当前代理节点功能，并优化列表、网格的定位滚动和代理页稳定性
  - 新增连接详情页面，补充连接信息标签与页面导航
  - 新增运行时规则搜索、筛选和临时启用/禁用功能
  - 新增按小时记录流量统计，改善统计数据写入与展示
  - 新增覆写**应用到配置**界面，可查看和修改覆写与多个订阅配置之间的绑定关系
  - 自定义分流配置支持跳过默认运行时 Patch，避免高级配置被应用自动修改
  - 新增外部 HTTP Provider 预取，订阅启动前会将 Provider 下载到对应配置目录
  - 订阅下载支持解析请求头、跟随重定向和自定义 User-Agent，并显示下载进度
  - 新增繁体中文和日语界面翻译，内置配置名称支持本地化
  - 修复首页设置、编辑器、自定义分流、远程控制器及无障碍操作的多语言缺失
  - 新增内核诊断导出；运行时、内核和配置测试日志统一为带时间戳的 `runtime.log`
  - 日志不再在每次启动时清空，保留完整错误原因并限制文件最大体积
  - 构建信息新增 mihomo 分支哈希与内核版本标记，便于识别和排查内核版本
  - 配置重载和远程控制器模式下继续显示代理入口与当前代理目标，减少页面状态跳变
  - 优化配置列表分区、底部操作面板和内置/导入配置的展示逻辑
  - 开源许可页面改为直接打开项目链接，精简中间弹窗
  - 优化启动流程，将重任务移至后台线程，并加强自动启动、会话追踪和运行状态恢复
  - 优化本地与 Root 运行时生命周期，防止过期会话、重复失败提示及连续启动竞争
  - 优化代理组启动校验：增加超时、中断响应、内核存活检查和错误日志回溯
  - 优化覆写执行，复用 JavaScript 运行时、跳过空覆写链，并避免应用操作等待运行时重载
  - 优化内置覆写的物化、元数据修复和配置处理，内置 DNS 防泄漏覆写改为 YAML 资源
  - 优化配置编辑器的系统栏与输入法边距，改善全屏编辑体验
  - 优化侧栏与双栏页面动画、圆角和模糊效果，侧栏改用 Haze 渲染
  - 修复 Provider 节点显示为未知类型、无法显示延迟以及单节点测速始终超时的问题
  - 修复默认 DNS 配置附加无效 `system://` 服务器，导致每次解析产生失败分支的问题
  - 修复 Root 守护进程连续启动时旧实例未完成退出、socket 路径被错误替换的问题
  - 修复原生内核子进程退出后未被回收而成为僵尸进程的问题
  - 修复 socket owner 消息发送被中断后不重试，以及已连接 Unix socket 处理异常的问题
  - 修复控制器密钥通过进程命令行暴露的问题

  - 修复无界面自动启动无法恢复运行时，以及停止流程残留本地状态的问题
  - 修复订阅空白导入、异常内容、图片资源类型或尺寸不合法等情况的处理
